# Anotações ADS — Base de Conhecimento

Vault colaborativa do curso de **Análise e Desenvolvimento de Sistemas da FATEC**, mantida em Markdown e organizada no Obsidian.

O objetivo é encontrar uma aula, conceito, exercício ou material em poucos segundos — sem transformar o cofre em uma estrutura difícil de manter.

- [Explorar o primeiro semestre](01%20-%20Painel/Primeiro%20Semestre.md)

> No Obsidian, abra esta pasta como um cofre e use `Ctrl/Cmd + O` para localizar notas pelos títulos e aliases.

## Estrutura

```text
00 - Caixa de Entrada/  Capturas rápidas ainda não classificadas
01 - Painel/            Início, mapas, base de notas, Canvas e guias
semestre-1/             Disciplinas, aulas, exercícios e materiais
semestre-2/             Início do segundo ciclo
99 - Templates/         Modelos para aulas, conceitos e revisões
.obsidian/              Configuração compartilhada da experiência
```

Cada disciplina possui uma nota `00 - ...` que funciona como **mapa de conteúdo (MOC)**. As aulas continuam dentro de suas pastas originais, agora conectadas por propriedades e links internos.

## Recursos nativos utilizados

- **Bases** para filtrar e agrupar aulas por disciplina, status e revisão;
- **Canvas** para navegar visualmente entre as matérias;
- **Properties** para padronizar semestre, disciplina, aula, data e estado;
- **Backlinks, outgoing links e graph** para revelar relações entre conceitos;
- **Templates** para manter novas anotações consistentes;
- **Bookmarks, quick switcher e busca global** para acesso rápido;
- **CSS snippet** sutil para destacar painéis e navegação.

## Convenções rápidas

1. Uma aula nova nasce do `Template - Aula`.
2. Use links internos com `[[...]]` sempre que um conceito já existir.
3. Marque `status: rascunho` quando faltar conteúdo e `revisao: true` somente após conferir a nota.
4. Imagens ficam em `semestre-1/Imagens`; materiais da disciplina ficam em `Materiais`.
5. Não versione executáveis, diretórios de build, configurações locais da IDE ou arquivos temporários.
