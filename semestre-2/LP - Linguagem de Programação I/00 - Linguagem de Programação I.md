# LP - Linguagem de Programação I

> [!abstract] Visão geral
> Estudo da linguagem C para escrever programas estruturados, compreender tipos e memória e aplicar os fundamentos de lógica em soluções executáveis.

## Percurso recomendado

1. Entenda de onde veio a linguagem C e por que ela continua relevante.
2. Reconheça a função `main`, os blocos e o ciclo de compilação.
3. Diferencie tipos, identificadores, variáveis e modificadores.
4. Pratique saída com `printf`, entrada com `scanf` e conversões de tipo.
5. Resolva os exercícios sem copiar os exemplos e teste cada programa.
